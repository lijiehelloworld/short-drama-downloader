# 签名代码来源

本目录中的 `branch_one.py`、`core.py`、`extra.py`、`header.py`、`helios.py`、`medusa.py`、`sign_proto.py`、`xgorgon.py` 保留自 [short-drama-downloader 的 `源码_开源版/liushen/flurl`](https://github.com/lijiehelloworld/short-drama-downloader/tree/93a68b965f51a4889382a2d12189f1273c6bf00e/%E6%BA%90%E7%A0%81_%E5%BC%80%E6%BA%90%E7%89%88/liushen/flurl)，用于兼容参考项目的视频请求签名。原项目的 MIT 许可见本目录的 `LICENSE`。

除 `extra.py` 中给 SM3 包装增加字符串转 UTF-8 的兼容处理外，此目录按上游代码保留。产品逻辑位于项目根目录的 Python 文件。
